I'm a second-year **BSc Data Science & Artificial Intelligence** student at the **University of East London**, engineering end-to-end systems across **AI/ML pipelines, cloud infrastructure, and full-stack automation**. My work centers on turning research-grade ideas into production-shaped systems — containerized services, streaming architectures, and secure, observable infrastructure.

Alongside coursework, I run a suite of personal infrastructure projects — a self-hosted privacy stack, automated Discord services, and a growing multi-agent Claude Code environment for parallelized engineering workflows.
